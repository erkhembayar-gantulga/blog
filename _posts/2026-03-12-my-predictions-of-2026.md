# 2026 онд болох тренд-н таамаг

LLM (AI) моделуудын чанар хэрхэн сайжирч байгааг бид бүхэн өдөр тутамдаа мэдэрсээр байна. Сүүлд гарсан моделуудын (Anthrophic Claude Opus 4.6, Google Gemini 3.1 Pro (3 Pro), GPT 5 моделиос хойш) чанар өдөр тутмын хэрэглээнд маш сайн үр дүнг үзүүлдэг болж чанарын хувьд бараг хоорондоо ялгаагүй боллоо.

Миний хувьд сүүлийн 2 жилийн хугацаанд LLM моделуудыг ажилдаа (мөн өдөр тутмын амьдралдаа) хэрхэн ашиглаж бүтээмжээ нэмэгдүүлэх талаар бодож хэрэглэхийг зорьж ашиглаж байна. Эхэндээ Cursor Editor -н төлбөртэй хувилбар ашиглан бүх сүүлд гарсан моделуудыг туршиж үзэж хоорондын ялгааг олж хараад, алыг нь юунд ашиглавал илүү үр дүнтэй болохыг нь өөртөө мэдрэмж авч, туршлага бий болохыг хичээсэн. Мөн өөрийн хэмжээнд translation (NMT) model сургаж болон [Transformer суурьтай моделиуд хэрхэн сурдаг](https://jalammar.github.io/illustrated-transformer/) болохыг ойлгож авахыг оролдсон. Сүүлд Claude Code болон Cursor Code гэх мэт tool-үүдийг өдөр тутамдаа ашиглаж байна.
Юунд ашиглаж байгаа жишээнүүдийг дурьдвал:
  - Алдаа засуулах (bugfix)
  - Код бичүүлэх (task implementation)
  - Гэрээ болон баримт хянуулах
  - Төлөвлөгөө гаргах (feature хөгжүүлэлт, weekly planning)
  - Ойлгохгүй байгаа зүйлээ судлуулж, ойлгож авах, цаашид ашиглах баримт бичиг боловсруулах. Жишээ нь: системийн шинжилгээ, process flow гэх мэт
  - Өгөгдлийн баазаас бодож байгаа зүйлээ шууд асууж үр дүнг тоогоор харах
  - Янз бүрийн тайлан мэдээг боловсруулуулж хялбар ойлгогдохиуц болгуулж авах (эрүүл мэндүүн шинжилгээний хариу, машины оношилгооны үр дүн - diagnostic tourble codes, угаалгын машины хоолойн тохируулах, материулыг хооронд нь хэрхэн нааж болох талаар олж мэдэх гэх мэт)
  - Юу хийхээ мэдэж байгаа мөртлөө яаж хийхээ мэдэхгүй байгаа зүйлээ хийлгүүлж авах (Strongswan ашиглаж IPsec-based VPN тохируулах)
  - End-to-end debug хийлгүүлэх (мобайл апп, backend API болон өгөгдлийн баазын өгөгдлийг хэрхэн хоорондоо өгөгдөл дамжуулсаныг MCP tool ашиглаж хянаж, үр дүнг шалгуулах)
  - Brainstorm хийх, Үнийн стратеги боловсруулах, давуу болон сул талуудыг гаргаж шийдвэр гаргахдаа ашиглах гэх мэт

Сүүлийн гарсан моделиудыг өдөр тутамдаа ашиглаж хэр ухаалаг болсныг мэдэрч байгаа хүний хувьд энэ чанарын сайжиралт 2026 онд юуг авчрах бодол сонирхлыг нь ихэд татаад байгаа учраас өөрийн зүгээс дараах байдлаар таамаг гаргалаа :haha.

## 2026 онд юу болох вэ ?

1. АНУ -н томоохон технологийн корпорацууд (Facebook, Google, Amazon etc)-с эхлэн ажлын байрны бүтцийн өөрчлөлтүүд хийнэ (цомхотгол)
2. Энэхүү трендийг дагаад дэлхйи даяар ажлын байрны бүтэц, цомхотголууд явагдана
3. Энэ трэнд ч гэсэн Монголыг тойрохгүй бөгөөд компани болгон AI модел ашиглахыг удирдлагуудаас чиглэл өгнө
4. Зарим бодит байдлаа дутуу үнэлсэн удирдлагууд шууд хүний тоогоо цөөлчихөж болно гэж бодоод алдаа гаргана. Ажлын үр дүнд/процессд алдаа гарч хохирол амсана *
5. Удирдлагууд хэрхэн компанидаа AI ашиглах талаар сонирхож, судалж ажил хэрэг болгоно


* Бодит байдлаа дутуу үнэлэх гэдгийг тайлбарлавал томоохон компаниуд LLM Agent/model -г хэрхэн ашиглаж бүтээмжээ бууруулахгүй цөөхөн хүнтэйгээр ажиллаж болох арга барилаа сайтар бэлдчихээд ажлын байрандаа бүтцийн өөрчлөлт хийж байгааг зарим удирдлагууд ойлгохгүйгээр (бэлтгэлээ хангахгүйгээр) шууд халчихаж болно гэж андуураад алдаа гаргах магадлалтай
